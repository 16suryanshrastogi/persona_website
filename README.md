# Suryansh Rastogi | Data Engineer

A responsive personal portfolio introducing Suryansh Rastogi's data engineering experience across Azure, data pipelines, lakehouse platforms, warehousing, and analytics.

## Portfolio

The single-page site includes:

- An introduction and example end-to-end Azure data platform flow
- Data engineering focus areas: orchestration, distributed processing, and analytical modeling
- A grouped technical toolbox
- An engineering approach centered on data quality, traceability, and reliable processing
- Links to LinkedIn and GitHub

The technology areas represented include Python, SQL, PySpark, Azure Data Factory, Azure Databricks, ADLS Gen2, Delta Lake, Azure Synapse Analytics, SQL Server, ClickHouse, Power BI, DAX, Logic Apps, Power Automate, and Azure DevOps.

## Run Locally

Requires Node.js and npm.

```bash
npm ci
npm start
```

The development server opens at [http://localhost:3000](http://localhost:3000).

## Available Scripts

- `npm start` starts the development server.
- `npm test` runs the test suite.
- `npm run build` creates an optimized production build in `build/`.

## Updating the Portfolio

- Edit page content and section structure in `src/App.js`.
- Update layout, colors, typography, and responsive styles in `src/DataPortfolio.css`.
- Update the page title and description in `public/index.html`.
- Update profile links in `src/App.js` when account URLs change.

Project case studies and measured outcomes should be added only when there are real project details to share.
